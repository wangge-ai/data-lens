# 2026-09 real-world paired evaluation

本轮使用历史真实任务，而不是为方法量身编写的小题。基础任务故意不给分析角度，用来观察候选能否自己识别核心问题。

| Case | 资料 | 公开状态 | 用途 |
|---|---|---|---|
| `kazike-72-mhtml` | 同一公众号 72 篇 MHTML，2026-05-06 至 2026-08-27 | 不分发原文；可公开分析输出 | 大语料、时间变化、共同机制与内部矛盾 |
| `xiaobei-18-articles` | 同一公众号 18 篇文章，2026-06-18 至 2026-08-25 | 不分发原文；可公开分析输出 | 小样本跨主题综合、证据强弱与商业主线 |
| `market-mixed-509` | 509 个混合业务文件，约 1.06 GB | 私有；不进入公开候选输出 | 多格式、多角色、市场判断与组织执行的本地压力测试 |

两组公开案例的基础提示词位于 `prompts/`。Skill 组在同一提示词前只增加“使用 `$data-lens`”，并增加一条交付要求：不要把内部路由、账本、哈希、审计过程或理论术语堆进读者正文。这条要求是 Data Lens 本身的既有读者输出规则，不是分析角度。

`market-mixed-509` 只在本地运行和评分。它的存在用于防止我们只在公开文章语料上调优；仓库不会保存原始路径、业务数据或可反推出经营信息的完整报告。

## 已揭盲结果

| Case | 裸智能体 | Data Lens 0.8.1 | 差值 | 盲评判断 |
|---|---:|---:|---:|---|
| `kazike-72-mhtml` | 83.5 | 88.5 | +5.0 | 达到本量表的实质增量信号 |
| `xiaobei-18-articles` | 81 | 89 | +8 | 达到本量表的实质增量信号 |

两组 Data Lens 候选都来自 0.8.1 预发布快照。它们都没有严重失败。Data Lens 的稳定优势出现在因果校准、竞争解释和把判断变成可失败的现实试验；裸智能体在跨期张力、内部矛盾、读者反馈利用和个别确定性计数上仍有独有优势。共同缺口包括：同一作者的叙事不能证明真实效果，负例库不完整，部分高风险外部事实未核验，而且两组都漏掉过原文内部的重要反证。最终 0.8.1 已据此补充规则，但未重跑或回改历史分数。

这两例说明当前 Skill 已出现可重复的正向增量，不足以证明跨资料类型的普遍优势。`market-mixed-509` 已完成裸智能体基线，但没有在完全相同条件下重跑 Data Lens 0.8.1，因此不报告一个看似精确但不可比的公开分数。

逐项证据、候选原文和揭盲映射分别保存在两个案例子目录中。结果同时保留裸智能体的长处、Skill 的长处和两者共同失败，不只展示总分。
