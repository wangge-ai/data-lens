# README illustrations

Three original concept illustrations created with the built-in image generation tool on 2026-09-05. They are explanatory artwork, not screenshots, test results, or a guaranteed output template. No private business data or third-party reference images were supplied. The original PNGs are included in this directory; both language editions share them and provide localized alternative text.

The older `data-lens-report-*` images are historical synthetic report screenshots, retained for existing links but no longer embedded in the landing page.
