# ChatLab / 微信会话导出

用于包含 `chatlab`、`meta`、`members`、`messages` 的本地 JSON 会话导出。它是通用质性语料路线的确定性适配器，不把聊天目录自动升级成共同主题。

## 先运行画像

```text
python scripts/data_lens.py profile-chatlab <paths...> --inventory inventory.json --output chatlab-profile.json
```

适配器负责：

- 按平台、会话类型和稳定会话目标识别同一会话；同会话多份导出只保留消息覆盖最完整的一份，其他进入版本账本；
- 把 JSON 文件、会话和消息分开计数，保留来源哈希、消息索引和平台消息 ID；
- 分开消息类型、会话类型、参与者、时间范围和词面候选；词面候选不能直接称为主题；
- 每个会话按早、中、晚三层，再按问题、实践、资源和长文本线索做确定性有界抽样；不顺序取前几条；
- 将图片、文件、语音和视频保留为辅助来源，未链接和审核前不进入内容结论；
- 记录解析失败、非 ChatLab JSON 和低覆盖导出，绝不静默丢弃。

## 宿主智能体接手

画像完成后，宿主智能体必须：

1. 阅读分层样本，按共同对象或问题划分资料群；“都是聊天记录”不是共同问题；
2. 将私人日常、业务协作、社群问答等不同语境保持分离，未经当前授权不跨群综合；
3. 提出角度候选、检查反例和替代解释，再交给角度与发现采用账本；
4. 只有需要证明图片、语音或文件内容时，才进入对应证据通道。

发送者标签和私聊内容属于本地敏感资料。真实运行产物不得复制到公开 fixture、Git 历史或公开报告；公共测试只使用脱敏合成形状。
