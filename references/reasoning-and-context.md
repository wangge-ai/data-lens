# 公共推理与情境规范

这是一组跨路线的推理护栏，不是新的分析路线，也不是固定报告目录。只有用户问题和现有证据确实涉及“为什么、如何变化、谁在行动、位置如何影响、规则如何作用”时才读取；普通归类、摘要或确定性统计不必强行使用。

这份规范用于帮助模型提出更深但仍可核查的解释。它不提供一套包打天下的世界观，也不能替代当前路线的方法文件和原始证据。

## 先从观察开始，不把答案写进问题

先确认现象，再命名机制。问题中出现“周期、红利、博弈、路径依赖、信息差、信任、平台分化”等词，不代表材料已经证明它们存在。

| 容易把答案预设进去的问题 | 改成可检验的问题 |
|---|---|
| 这处于哪个阶段？ | 现有资料是否显示可区分的阶段？若显示，各阶段由什么起止信号定义？ |
| 谁在利用信息差获利？ | 规则或变化发生前，哪些参与者、问题和行为已经存在？信息可得性是否真的不同？ |
| 各方的最佳策略是什么？ | 资料显示有哪些可选行动、实际行动、约束和后果？尚未观察到哪些选项？ |
| 为什么平台机制导致了下滑？ | 下滑是否成立？与哪些候选解释兼容？还要什么证据才能区分平台、数据口径、供给、需求或执行因素？ |
| 作者为什么故意这样写？ | 文本中出现了什么写法？作者是否自述理由？还存在哪些同样能解释该写法的原因？ |

不得只搜索支持已命名机制的材料。没有观察到必要条件时，应写“当前证据不支持”，而不是换一种说法保住原假设。

## 四种证据职责

同一条材料在一次解释中明确承担一种主要职责：

- **触发现象**：证明值得解释的变化、差异、重复或异常确实出现；
- **支持证据**：与某个候选解释一致，但单独不能排除其他解释；
- **区分证据**：能让两个或多个候选解释得到不同预测，是升级判断的关键；
- **反证或冲突证据**：与当前解释不一致，或迫使它缩小适用范围。

“出现在线索旁边”不等于支持，“与解释相容”不等于排他性证明。重要解释至少要说明现有证据属于哪一类，以及还缺什么区分证据。

## 候选机制卡

需要解释原因时，先生成两个以上合理候选。若现有材料不足以提出第二个合理候选，就不形成重要机制结论，只交付已观察描述、当前猜想和证据缺口。每个候选至少回答：

1. 它要解释的可观察现象是什么？
2. 若它成立，还应该观察到什么？
3. 当前有哪些支持、冲突和缺失证据？
4. 有哪些替代解释也能产生相同现象？
5. 哪条新增证据、对照或时间记录能区分它们？
6. 该解释适用到哪个对象、时期、平台或群体，不能外推到哪里？

统一使用以下判断强度：

- `已观察`：材料直接记录了现象；
- `与解释相容`：没有冲突，但尚不能排除替代解释；
- `当前证据更支持`：已有区分证据使某候选相对占优；
- `暂时无法区分`：多个候选仍同样合理；
- `当前证据不支持`：必要条件缺失或存在直接冲突。

不要用“底层逻辑”“本质上”“必然”掩盖证据等级。

## 人、行为和动机分开

分析参与者时，依次记录：

- 说了什么；
- 做了什么；
- 发生了什么结果；
- 角色、权限和责任；
- 可获得的资源和信息；
- 激励、约束与可选行动；
- 动机是否有直接证据。

作者或当事人的自述只能证明“他这样解释自己的行为”，不能自动证明真实动机或实际因果。行为符合某种利益，只能说明该动机假设与行为相容。文风、选题、结果数据和单次行为不能直接推出人格、价值观、操纵意图或群体心理。

## 时间主张类型与证据门

时间结论选择与证据相匹配的主张类型，不能用较弱证据支撑较强主张。下列编号用于检查，不代表严格的前置链：阶段、滞后、周期和因果是不同分支；例如合格的因果设计不需要先证明存在周期。

1. **时间点**：某时刻的记录；
2. **先后顺序**：A 早于 B；
3. **变化**：两个或多个可比时间点不同；
4. **局部趋势**：有限窗口内出现持续方向；
5. **阶段转换**：存在明确且可复核的起止信号；
6. **滞后关系**：一个变化后，另一个指标在预先定义的窗口内响应；
7. **重复周期或季节性**：跨多个完整周期重复出现；
8. **因果效应**：有对照、排除或其他足以识别因果的设计。

使用时间解释时遵守：

- 两个时间点通常只能证明变化，不能证明趋势或周期；
- 十天、二十天等短窗口通常只能描述局部变化，除非已知并覆盖完整业务周期；
- 历史分位数不等于周期顶部或底部；
- “阶段”必须写清开始、结束和判定指标；
- 不同时间轴不能只因日期相近就对齐；
- 先后发生不能单独证明因果，滞后窗口不能事后随结果移动。

## 空间与解释尺度

先声明解释尺度：个人、群体、组织、平台、市场或制度。不得用一个尺度的证据直接解释另一个尺度的结论。

“空间”可以是地理位置、平台生态、组织边界、关系网络、信息可达范围、渠道或市场。平台之间数值不同只证明平台差异，不自动构成空间机制。只有当位置改变了可达资源、信息、规则、交易成本、受众或行动边界时，空间才进入解释。

## 形成条件与当前条件

只有资料同时包含历史形成过程和当前运行状态时，才比较：

- 最初要解决的问题；
- 当时可用的资源、约束和替代方案；
- 哪些选择被固定下来；
- 当前环境发生了什么变化；
- 原选择继续存在的机制；
- 切换成本、反馈或制度安排是否有直接证据。

只看到“旧做法仍在”不能诊断路径依赖；也可能是当前仍有效、没有替代方案或资料未覆盖变化。

## 规则和系统的中性检查

分析规则、平台政策或组织制度时，先做中性描述：

1. 规则原文及适用范围是什么？
2. 涉及哪些参与者？
3. 权利、义务、权限和执行方式如何变化？
4. 变化前后有哪些可观察行为和结果？
5. 成本、负担、风险或收益转移是否可量化？
6. 规则还有哪些可能目的或非预期效果？

不得默认规则制定者只有单一目的，也不得把所有规则解释成“控制”“降低成本”或“利益转移”。规则文本证明制度内容，行为数据证明观察到的响应，动机仍需独立证据。

## 面向读者的表达

这些检查主要用于内部推理，不要把整套框架机械复制进报告。报告只展示与决策有关的：

- 已确认现象；
- 当前最有解释力的候选机制；
- 最关键的反例或替代解释；
- 结论适用范围；
- 能区分解释的下一步补证或测试。

如果证据只能支持描述，就交付清楚的描述，不为显得深刻而强造机制。

## 禁止的推理捷径

- 把信息不对称、利益博弈、信任、周期或路径依赖当成所有问题的第一解释；
- 用一个作者反复表达的观点充当多个独立来源；
- 用“行为符合利益”确认真实动机；
- 用自述确认实际因果；
- 用短期波动命名完整阶段或周期；
- 用平台差异直接推导平台机制；
- 用主题相似、时间接近、文件邻近或共同出现确认关系；
- 用“人性如此”“社会就是这样”代替可以观察和反驳的机制；
- 把固定行业阶段、人格类型或二元角色套到所有新资料上。
